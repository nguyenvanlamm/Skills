# Idea Brainstorming Framework

Use this framework to analyze each topic and synthesize ideas.

## Topic Analysis Template

```
## Topic: {name}
- Growth: {growth_pct}% (24-month)
- Search Volume: {search_volume}/month
- Core Need: What fundamental human/market need does this serve?
- Target Audience: Who is the primary user/customer?
- Growth Drivers: Why is this trending now? (tech shift, cultural change, regulation, etc.)
- Pain Points: What frustrations exist in this space?
- Existing Solutions: Who are the current players?
```

## Idea Synthesis

After analyzing all 15 topics:

1. **Cluster needs** — Group topics by shared core needs
2. **Identify gaps** — Look for needs that are underserved or have fragmented solutions
3. **Cross-pollinate** — Combine insights from different clusters for novel ideas

## Idea Template

```
### Idea N: {name}

**Elevator Pitch:** One-sentence description.

**Core Need Addressed:** Which specific need(s) from the topic analysis does this serve?

**How It Works:** 2-3 sentence explanation of the product/service.

**Target Audience:** Who will use this first? (be specific)

**Why Now:** What makes this timely?

**Go-to-Market Sketch:**
- Channel: {e.g., TikTok organic, SEO content, paid search, B2B sales}
- Hook: {the compelling message}
- First 90 days: {key milestones}

**Monetization:** {e.g., subscription, marketplace, affiliate, SaaS}

**Risk Factor:** What could go wrong?
